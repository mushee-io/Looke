## Actual operator flows

2. `GET /api/social/ops/beta` is *read-only* and moderator-only. Lists at most 12 genuine unsuspended creator profiles and 12 actually visible, moderated posts from PostgreSQL. Pending/rejected media never appears. Social asset references are labelled unverified until independently checked. The report includes actual Points reconciliation and index scan/rewind history.
3. In the asset proof field, paste a **public factory address + actual CoinCreated tx hash** or **native Ultra Testnet account + factory ID + Uniq token ID**. Backend independently re-reads transaction receipt, chain ID 18881, current deployed token code and creator state, or current native owner/factory record. A missing or invalid receipt is `blocked`; no fabricated token or NFT is created.
4. Wallet signature proof: `npm run m22:witness -- create --wallet 0xPUBLIC_ADDRESS --origin https://EXACT-SSO-PREVIEW.vercel.app --commit EXACT_40_CHAR_SHA`. Have the holder personally sign **only** the returned EIP-191 message using their wallet's message-signing option; never disclose a seed phrase, secret, or private key. Save public `{challenge,signature}` JSON. Verify via `npm run m22:witness -- verify --file signed.json --origin https://EXACT-SSO-PREVIEW.vercel.app --commit EXACT_40_CHAR_SHA`, or the moderator-only read-only `POST /api/social/ops/beta/witness` when `LOOKE_M22_PREVIEW_ORIGIN` and `VERCEL_GIT_COMMIT_SHA` are set. This is **cryptographic key control only**. It does not issue or consume an auth challenge in the database, create a real social session, prevent replay, prove a unique human or satisfy the independent human wallet acceptance gate.
