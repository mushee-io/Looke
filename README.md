# Looke

Looke is an Ultra-first creator platform in development: creator coins on **Ultra EVM**, native **Uniq** NFT integration on **Ultra**, and social discovery.

**Status:** repository bootstrapped. No contracts are deployed by this commit; token trading, NFT minting and messaging are not live.

The first implementation will be developed on a feature branch. Code reuse from Zora is limited to appropriately licensed portions, with notices retained.
